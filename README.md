# Эмулятор командной оболочки

Вариант №28. Практическая работа №1 по дисциплине
«Конфигурационное управление», РТУ МИРЭА, ИКБО-40-25.

## Описание

Консольный (CLI) эмулятор командной оболочки UNIX-подобной ОС
на Python. Эмулятор ведёт диалог с пользователем: выводит
приглашение, читает команду, выполняет её и печатает ответ.

Приглашение к вводу формируется из реальных данных ОС,
в которой запущен эмулятор: имени пользователя и имени компьютера.

    julia@MacBook-Pro-Ula:~$

Эмулятор настраивается параметрами командной строки, умеет
выполнять стартовый скрипт и работает с виртуальной файловой
системой (VFS): каталог на диске целиком загружается в память,
а исходные файлы не изменяются.

## Требования

- Python 3.10 или новее

Сторонние библиотеки не используются.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `src/main.py`   | точка входа: параметры, отладочный вывод, запуск |
| `src/config.py` | параметры командной строки и стартовый скрипт |
| `src/repl.py`   | консольный интерфейс: приглашение, ввод, вывод |
| `src/shell.py`  | ядро: разбор строки и выполнение команд |
| `src/vfs.py`    | виртуальная файловая система в памяти |
| `src/errors.py` | исключения эмулятора |
| `tests/`        | модульные тесты |
| `examples/`     | стартовые скрипты эмулятора |
| `scripts/`      | скрипты ОС для проверки эмулятора |
| `vfs/`          | тестовые VFS |

## Запуск

    ./run.sh [--vfs PATH] [--script PATH]

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH`    | путь к физическому расположению VFS — каталогу на диске |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help`  | справка по параметрам |

Оба параметра необязательны. Без `--vfs` эмулятор работает
с пустой VFS. При запуске выводятся все параметры и сводка
по загруженной VFS (отладочный вывод):

    [debug] параметры запуска:
    [debug]   vfs = vfs/deep
    [debug]   script = examples/start_demo.txt
    [debug] VFS в памяти: каталогов 8, файлов 6

Путь к стартовому скрипту проверяется: он не должен быть
пустым, файл должен существовать и быть именно файлом.
Путь к VFS должен вести к существующему каталогу. При ошибке
эмулятор пишет `ошибка запуска: ...` и завершается с кодом 1.
Неизвестный параметр — код 2.

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку.
Пустые строки и строки, начинающиеся с `#`, пропускаются.

Команды выполняются по порядку. На экране отображаются и ввод,
и вывод, как будто команды вводит пользователь. **На первой
ошибке выполнение скрипта останавливается** с сообщением

    стартовый скрипт остановлен: ошибка в строке N

После скрипта эмулятор переходит в интерактивный режим.
Команда `exit` в скрипте завершает работу эмулятора.

| Файл | Содержание |
|------|------------|
| `examples/start_demo.txt`  | команды без ошибок |
| `examples/start_error.txt` | ошибка в середине: последняя строка не выполняется |
| `examples/start_vfs.txt`   | все команды этапов 1–3, `vfs-save` и ошибка в конце |

### Виртуальная файловая система

Источник VFS — каталог на диске пользователя. При запуске
каталог целиком читается в память: структура каталогов и
содержимое файлов (в том числе двоичных) в виде байтов.
Дальше эмулятор работает только с копией в памяти; исходный
каталог не распаковывается и не изменяется. Символические
ссылки при загрузке пропускаются.

Если в корне VFS есть файл `motd`, его текст выводится
при запуске эмулятора.

Состояние VFS можно сохранить на диск командой `vfs-save`.
Сохранение выполняется в исходном формате — в виде каталога
с той же структурой и теми же файлами.

Тестовые VFS в каталоге `vfs/`:

| Каталог | Содержание |
|---------|------------|
| `vfs/minimal` | минимальная VFS: один файл `motd` |
| `vfs/flat`    | несколько файлов в корне, без `motd` |
| `vfs/deep`    | `motd` и вложенные каталоги глубиной до 5 уровней |

## Команды

| Команда | Описание |
|---------|----------|
| `ls [аргументы]` | заглушка: выводит своё имя и аргументы |
| `cd [каталог]`   | заглушка: выводит своё имя и аргумент; больше одного аргумента — ошибка |
| `exit`           | завершает работу эмулятора; аргументы не принимает |
| `vfs-save путь`  | сохраняет состояние VFS на диск в виде каталога |

Строка ввода разделяется на команду и аргументы по пробелам.
Несколько пробелов подряд считаются одним разделителем.

Об ошибках эмулятор сообщает и продолжает работу:

| Ситуация | Сообщение |
|----------|-----------|
| неизвестная команда | `wat: команда не найдена` |
| лишние аргументы у `cd` | `cd: слишком много аргументов` |
| аргументы у `exit` | `exit: аргументы не поддерживаются` |
| `vfs-save` без пути или с лишними аргументами | `vfs-save: нужен ровно один аргумент — путь` |
| путь для `vfs-save` уже существует | `vfs-save: out/copy уже существует` |
| сохранение внутрь исходной VFS | `vfs-save: нельзя сохранять внутрь исходной VFS` |

Команда `vfs-save` создаёт недостающие родительские каталоги,
но никогда не перезаписывает существующие файлы и каталоги.

Работу также завершает конец ввода (Ctrl+D). Ctrl+C сбрасывает
текущую строку, не завершая эмулятор.

## Примеры использования

Интерактивная работа:

    $ ./run.sh
    julia@MacBook-Pro-Ula:~$ ls -la /home
    ls: аргументы: -la, /home
    julia@MacBook-Pro-Ula:~$ cd docs
    cd: аргументы: docs
    julia@MacBook-Pro-Ula:~$ cd a b
    cd: слишком много аргументов
    julia@MacBook-Pro-Ula:~$ wat
    wat: команда не найдена
    julia@MacBook-Pro-Ula:~$ exit

Запуск со стартовым скриптом, остановка на ошибке:

    $ ./run.sh --script examples/start_error.txt
    [debug] параметры запуска:
    [debug]   vfs = (не задан)
    [debug]   script = examples/start_error.txt
    julia@MacBook-Pro-Ula:~$ ls
    ls: вызвана без аргументов
    julia@MacBook-Pro-Ula:~$ cd docs
    cd: аргументы: docs
    julia@MacBook-Pro-Ula:~$ wat
    wat: команда не найдена
    стартовый скрипт остановлен: ошибка в строке 7
    julia@MacBook-Pro-Ula:~$

Запуск с VFS: выводится `motd`, состояние VFS сохраняется:

    $ ./run.sh --vfs vfs/deep
    [debug] параметры запуска:
    [debug]   vfs = vfs/deep
    [debug]   script = (не задан)
    [debug] VFS в памяти: каталогов 8, файлов 6
    Добро пожаловать в VFS с несколькими уровнями каталогов!
    Сегодня в программе: vfs-save и motd.
    julia@MacBook-Pro-Ula:~$ vfs-save out/copy
    vfs-save: VFS сохранена в out/copy
    julia@MacBook-Pro-Ula:~$ vfs-save out/copy
    vfs-save: out/copy уже существует
    julia@MacBook-Pro-Ula:~$ exit

## Сборка и тесты

Сборка не требуется: Python — интерпретируемый язык,
сторонние библиотеки не используются.

Модульные тесты:

    python3 -m unittest discover tests

Скрипты ОС для проверки эмулятора. Ввод в них закрыт,
поэтому после стартового скрипта эмулятор сразу завершается:

| Скрипт | Что проверяет |
|--------|---------------|
| `scripts/test_params.sh` | запуск без параметров, с каждым параметром и с обоими |
| `scripts/test_errors.sh` | остановку скрипта на ошибке, ошибки параметров и VFS |
| `scripts/test_vfs.sh`    | все тестовые VFS: загрузку, `motd`, `vfs-save` и сравнение копии с исходником |

Копии VFS, сохранённые скриптами, попадают в каталог `out/`,
который не входит в репозиторий.
